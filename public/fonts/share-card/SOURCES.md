# Share card fonts

These font files are bundled so server-side PNG rendering never depends on
fonts installed on the host operating system.

- `Inter-Regular.ttf` — Inter 4.1, from <https://github.com/rsms/inter>, SIL
  Open Font License 1.1.
- `NotoSansCJKsc-Regular.otf` — Noto Sans CJK SC, from
  <https://github.com/notofonts/noto-cjk>, SIL Open Font License 1.1.
- `NotoSansSymbols-Regular.ttf`, `NotoSansSymbols2-Regular.ttf`, and
  `NotoSansMath-Regular.ttf` — Noto fonts, from
  <https://github.com/notofonts/noto-fonts>, SIL Open Font License 1.1.
- `DejaVuSans.ttf` — DejaVu Sans, from <https://dejavu-fonts.github.io/>,
  included as the final compatibility fallback under the DejaVu Fonts license.

The accompanying license files are retained verbatim from their upstream
repositories.
